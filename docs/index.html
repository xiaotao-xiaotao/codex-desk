01 — WORKSPACE

平时安静地待在桌面。展开后，额度、用量趋势和本地会话，都在眼前。Quietly on your desktop. Open it up for your quota, usage trends, and local sessions in one place.

额度监控Quota monitoring

查看额度窗口、使用比例与重置时间。启用通知后，在接近用量阈值时收到提醒。Check quota windows, usage, and reset times. Enable notifications to get a heads-up as usage reaches alert thresholds.

02 /

会话接续Session continuity

搜索历史对话，查看文件变更。复制恢复命令，就能在终端里继续之前的会话。Find a conversation and review its file changes. Copy the resume command to carry on in your terminal.

03 /

用量洞察Usage insights

按天查看 Token 用量和活动趋势，了解自己的工作节奏。数据来自本地会话记录。Explore daily token usage and activity trends. Understand your work patterns from local session records.

02 — LOCAL BY DESIGN

会话留在本地Your context, local.

账户、额度和会话通过本机 Codex 进程读取。Codex Desk 不读取或保存 auth.json，也不向第三方服务上传本地会话数据。Account, quota, and session data come from your local Codex process. Codex Desk never reads or stores auth.json, or uploads local session data to third-party services.

检查更新时，仅请求 GitHub 上的公开版本信息。Update checks only request public release information from GitHub.
