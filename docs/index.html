Windows 10/11 · macOS · Linux

让日常使用 Codex 更方便

悬浮额度监控

在桌面随时查看额度状态与重置时间。启用通知后，在用量达到阈值时收到提醒。

会话管理与恢复

搜索本地会话、查看对话与文件变更，复制恢复命令继续工作，也能导入和导出会话。

本地用量洞察

查看 Token 用量与活动趋势。账户和会话数据在本机处理，不上传到第三方服务。

两步开始使用

  1. 先安装 Codex CLI：npm install -g @openai/codex，然后运行 codex 完成登录。
  2. 从 Releases 下载对应系统的 Codex Desk 安装包，安装后启动。
